# 同人视觉风格实验 / 提示与手部约束

## 冬站孔版 / 逢坂大河

- 风格：冬日铁路站、暖灰孔版印刷、纸张颗粒。
- 手部：一只手自然握纸杯，另一只手完整放入口袋；不生成额外手指或穿模。

## 午夜甜甜圈气刷 / 忍野忍

- 风格：80 年代商业气刷、蒸汽波夜店色彩、金属柜台反光。
- 手部：一只手从下方托住甜甜圈，另一只手平放；两手各五指，指甲和腕部连续。

## 城墙蓝晒档案 / 三笠·阿克曼

- 风格：蓝晒、建筑图纸、速写档案与日出实景叠加。
- 手部：一只手捏住围巾边缘，另一只手自然下垂；禁止武器握持和复杂交叉动作。

## 孟菲斯相机日 / 锦木千束

- 风格：孟菲斯几何图形、明亮咖啡店、商业目录摄影。
- 手部：一手简单握相机机身，一手张开；五指清楚，拇指方向正确。

## 通用验收

- 人物面部、腕部、手掌、手指和指甲需逐张放大检查。
- 不采用六指、粘连、断腕、错误握持、暗部多余肢体或异常反射的候选。
- 不生成文字、Logo、水印；展示稿仍需根据输出尺寸进行人工裁切和色彩检查。
