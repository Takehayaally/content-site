Scope角色资产 / 世界观 / 文件归档

Output资产索引 / 源文件包

01 / Asset Families

用同一规则管理不同题材的角色。

02 / Asset Contract

每个项目都要回答“有什么、能做什么、是否能交”。

资产层必须保留适用输出
角色基线四视图/设定、配色、服装分区、道具与禁止漂移项。人物初稿、表情、动作、分镜和系列图。
世界规则环境、身份功能、事件逻辑、反复出现的符号与材质。场景图、故事卡、商品命名与内容选题。
生产素材透明 PNG、PSD/SVG、刀线、检查预览、版本与说明。立牌、包装候选、详情页和供应商沟通前置材料。
QA 状态通过稿、待补项、不可公开项和生产候选边界。避免未确认内容混进展示、交付或后续生成。

03 / Reuse Path

同一角色，可用在不同任务，不能失去同一身份。

01 / SPEC设定与锚点
02 / DRAFTGPT Image 候选
03 / QA筛选与后期
04 / REUSE场景 / 商品 / 文件

复用时允许调整镜头、动作、环境和载体，但不允许无说明改变角色身份、核心服装、标志道具或产品结构。每次新增画面都先回到设定包，再进入候选与 QA。
