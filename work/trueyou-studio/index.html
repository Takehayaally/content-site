Case 06 / Image Production System

把一组好图，变成可管理的生产过程

TrueYou Studio 关注的不只是生成结果，而是素材、方案、成本、质检和交付状态能否在同一套流程里被看见和复核。

Problem产物多、状态散、质量难追踪
Role产品流程 / 视觉 QA
Output生产台 / 方案库 / 系列图
Status本地案例 / 系统建设中

系列图库

只选四张代表画面，分别覆盖近景、动作、桌面和全身构图。图库用于观察系列一致性，不替代完整生产记录。

项目价值

当图片项目从一张扩展到一组，真正的难点会变成状态、版本和质量控制。生产台负责让“现在卡在哪里”可见，联系表负责让“这一组是否像同一个系列”可判断。

  • 01降低沟通成本：任务与状态集中呈现
  • 02提高交付稳定性：方案、质检和交付有明确门槛
  • 03减少返工：先看整组一致性，再决定单张精修

提示词如何参与

提示词不是越长越好，而是把可观察的要求拆成可检查的模块。下面是公开展示用的脱敏结构示例，保留方法，不暴露内部角色资料、完整模板或运行凭据。

01 / SUBJECT主体与身份锚点

年龄段、轮廓、发型、服装结构和不可漂移特征。

02 / CAMERA镜头与动作

景别、视角、身体朝向、视线目标和手部位置。

03 / LIGHT环境与材质

光线方向、色温、背景层次和材质表现。

04 / QA负面约束与验收

明确禁止项，并回到整组检查一致性、裁切和可交付性。

PUBLIC EXCERPT / SANITIZED结构示例

[主体] 保持既定人物轮廓、发型与学院制服结构；同一系列中不改变核心识别点。

[镜头] 三分之四身，视线略偏离镜头；手持书本，手指结构自然，动作与重心一致。

[环境] 深色木质学院空间，暖色烛光与冷色窗光形成层次；服装材质真实，不出现塑料感。

[验收] 检查脸部一致性、手部结构、服装徽记、光线方向、边缘融合与整组色彩连续性。

这里公开的是可沟通、可验证的方法。实际生产仍由参考资产、版本哈希、负面约束和人工 Release Decision 共同决定，单独一段 Prompt 不等于可交付结果。
