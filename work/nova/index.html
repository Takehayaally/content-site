Case 01 / Original IP System

NOVA：从角色到商品系统

不把角色停在一张主视觉里，而是建立能进入徽章、立牌、卡牌、包装与陈列的统一识别系统。

Scope角色视觉 / 商品延展

OutputKV / 周边 / 包装 / 陈列
Status原创公开案例

01 / Brief

让视觉识别可以跨载体成立。

角色的黑色服装、冷蓝透明材质、几何光环与红色签条构成核心锚点。设计重点不是增加更多装饰，而是在不同尺寸和材质里保留这些识别线索。

  • 01
    轮廓先于细节
    大面积深色与透明外层形成远距离可识别的剪影。
  • 02
    冷色系统中保留一个热色信号
    红色签条承担视线停留点，不与蓝色科技氛围平均竞争。
  • 03
    同一锚点适配不同商品尺度
    主视觉保留环境，徽章和卡牌则优先保留脸部、光环与红色标识。
