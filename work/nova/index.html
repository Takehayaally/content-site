Case 02 / Original IP System

NOVA：从角色到商品系统

不把角色停在一张主视觉里，而是建立能延展到徽章、立牌、卡牌、包装候选与陈列提案的统一识别系统。

Scope角色视觉 / 商品延展
RoleAI 辅助生成 / 筛选 / 视觉组织
OutputKV / 周边 / 包装候选 / 陈列提案
Status原创概念案例 / 待签样

01 / Brief

让视觉识别可以跨载体成立。

角色的黑色服装、冷蓝透明材质、几何光环与红色签条构成核心锚点。设计重点不是增加更多装饰，而是在不同尺寸和材质里保留这些识别线索。

  • 01
    轮廓先于细节
    大面积深色与透明外层形成远距离可识别的剪影。
  • 02
    冷色系统中保留一个热色信号
    红色签条承担视线停留点，不与蓝色科技氛围平均竞争。
  • 03
    同一锚点适配不同商品尺度
    主视觉保留环境，徽章和卡牌则优先保留脸部、光环与红色标识。

03A / Individual Products

把周边拆成可单独阅读的商品图。

03 / Display Proposal

让同一套识别进入空间。

陈列不额外发明一套语言，而是继续使用角色的深色轮廓、冷蓝光线和红色信号。它用于检验商品、角色和空间是否仍然指向同一个视觉中心。

04 / Deliverables

把角色系统翻译成岗位能接手的文件。

01 / KEY VISUAL

角色锚点页

轮廓、冷蓝材质、几何光环与红色标识作为跨图基准。

02 / MERCH

SKU 延展页

徽章、立牌、卡牌和包装候选按载体尺寸拆分视觉重点。

03 / DISPLAY

陈列提案页

用空间层级验证商品组合，不把概念陈列写成真实门店。

05 / Handoff Structure

文件结构为后续制作留下接口。

核心资产
角色主视觉、透明背景素材、标识与配色锚点。
商品分支
按徽章、立牌、卡牌、包装候选分别建立版面与裁切。
检查项
小尺寸识别度、红色信号位置、透明材质边缘与文字后置。

当前公开页展示的是视觉系统和生产准备方式；没有把未完成的刀模、专色、白样或签样记录写成既有交付。

06 / Production Boundary

展示提案不等于生产完成。

本页展示原创角色的稳定公开版本与已形成的商品视觉组合。盲盒和其他包装仍为生产候选：尚未取得供应商正式刀模、CMYK/专色输出、白样、彩样或签样记录。后续可以补足生产规格、单品展开与更严格的跨图一致性记录；在这些内容实际完成前，不把它们写成既有成果。

07 / Source Pack

角色、世界与四视图都有来源文件。

林澈的角色设定、四视图提示词、栖光市世界规则和配件说明均可公开核对；商品视觉仍保持“生产候选”状态，不把源文件存在混同为已经量产。
