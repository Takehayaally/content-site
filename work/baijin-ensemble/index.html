Character Case / Ensemble Design

白烬：同一世界里的角色差异化。

把主角之外的角色也做成可进镜头的设定：先共享世界观规则，再用轮廓、材质、道具和行动职责拉开距离，避免多人同时出现时失去辨识。

01 / Shared Rules

先统一世界，再区分角色。

三位角色共享冷灰基底、黄铜机械细节与“记忆维护”语境；这让他们同场时有共同的世界来源。差异不依赖随机换色，而来自服装明度、外轮廓、随身工具和角色面对镜头时的姿态。

02 / Anchor Sheet

能复核的角色基线。

多人剧情不能只靠一张氛围图记住角色。白烬的四视图把发色、轮廓、服装分区与装备位置固定为基线；后续不同景别或动作的候选图需要回到这些锚点检查。

03 / Scene Task

让设定在剧情任务中继续成立。

进入场景时，角色不只是“站在背景前”。本张关键帧把白烬放进雪夜追踪的行动任务：前景障碍、行进方向和冷暖对比共同服务镜头阅读。生成候选会先检查脸部、发色、外套结构与装备位置，再判断动作和环境是否支持任务。

04 / Handoff

交给分镜与生成的最小信息集。

必须保留
角色轮廓、主色、专属道具、服装结构和身份功能。
可随镜头变化
景别、姿态、环境密度、光源方向与情绪强度。
生成后检查
人物数量、发色与服装漂移、手部/道具关系、行动方向和场景可读性。
