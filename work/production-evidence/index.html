P0 Evidence / Public Production Notes

从角色锚点，到可交接素材。

这是一页制作证据，不是把一张生成图包装成“完成项目”。它说明原创 IP 如何用结构化要求生成候选、由人工筛选与后期整理，并以可编辑文件、检查项和明确边界交接。当前公开的是静态镜头预演与素材流程，不把它写成正式动态成片。

01 / Anchor

先固定“什么不能变”。

每次生成之前，先把人物的轮廓、发型、服装结构、主色、关键配件和情绪范围写成锚点。镜头、动作和场景可以变化，但不能把这些身份信息交给随机结果决定。

01 / CHARACTER角色锚点
02 / SHOT镜头与动作
03 / CANDIDATE候选与筛选
04 / RELEASEQA 与交接

角色基线可先从 赵霜角色设定系统 ↗ 阅读；如需看角色在世界观与道具中的叙事延展，可继续查看 白烬案例 ↗。

02 / Prompt

提示词是可审查的需求单。

公开的结构保留主体、镜头、环境与禁用项四部分。它让编剧、剪辑或协作方能指出“哪一项不对”，而不是只说“这张感觉不对”。完整提示词与对应图片编号保存在原创项目档案中；含参考图的版本必须与前序图一起使用，才能维持同一角色的基线。

01 / SUBJECT主体与身份

人物轮廓、发型、服装结构、配件和不可漂移的识别点。

02 / CAMERA镜头与动作

景别、视角、视线、身体朝向、手部位置和动作重心。

03 / ENVIRONMENT环境与材质

光线方向、色温、背景层次、材质表现与画面留白。

04 / CONSTRAINT禁用项与验收

不允许出现的文字、标识、结构错误和角色漂移，并回到组图检查。

提示词公开的是创作与沟通方法；它不包含账号、运行凭据或未公开的第三方资料。

03 / Editable

把可编辑与不可编辑分开说清楚。

以白烬亚克力立牌候选为例：角色印刷层、白墨参考、闭合矢量刀线和底座刀线各自独立；生产预览只用于检查，不混入交付图层。对应 PSD 已重开核验为 2480 × 3508 px、300 ppi、6 个图层/图层组，所列必需图层齐全。

  • 01
    位图不伪称分层工程
    生成原图是位图源；只有实际存在的 PSD、SVG 和可编辑版式对象才标为可编辑。
  • 02
    印前层不等于已量产
    当前有图层、刀线和尺寸说明；色彩模式、专色、插槽公差、供应商模板与签样仍须在量产前单独闭环。
  • 03
    版本与交付可追溯
    每张候选关联提示词编号、检查图和对应文件角色，避免裁切图覆盖母图或混淆版本。

04 / QA

先看整组，再决定单张是否放行。

发布或交接前，先检查同一人物、色彩、材质和世界观是否在一组画面中连续；再检查裁切、边缘、手部、文字与小结构。裁切和详情图使用已选母图的确定性复用，不把它们伪装成新的生成结果。

需要看系列图的整组一致性与状态管理，可继续查看 图片生产与质检案例 ↗；需要看剧本如何先拆成镜头检查，可查看 AI 短视频镜头预演 ↗。

05 / Boundary

公开证据，也保留真实边界。

已展示可核查的内容仍需在真实项目中确认
角色与提示词角色锚点、公开提示词结构、对应图片编号与组图检查方法。正式剧本、客户资产和协作要求按项目授权处理。
可编辑文件PSD 重开信息、PNG / SVG 图层角色、尺寸与生产说明。供应商模板、色域、专色、公差和签样不以概念文件替代。
图片与视频候选筛选、人工后期、静态镜头预演与 QA 方法。未完成的成片、上线表现和商业结果不作为既有成果声明。

本页所有制作样例均为原创公开过程材料；不把它们写成真实客户项目、已上线内容或已经量产的商品。
