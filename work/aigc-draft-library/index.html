P0 / P1 AIGC Draft Library

不是只展示“最好的一张”，而是展示怎么选。

把多个原创项目中的 AIGC 初稿、候选筛选和人工统一集中在一页：先看需求，再看候选，最后看为什么这张能进入角色设定、场景或商品页面。

Scope角色 / 场景 / 商品初稿
RoleGPT Image / 筛选 / 后期
Output候选板 / 通过稿 / QA
Status原创公开案例

01 / Draft Types

四种初稿，四种判断任务。

初稿不是一个单一风格标签。角色设定看稳定性，剧情画面看任务，商品图看结构，氛围图看世界观。将它们放在同一个筛选框架下，才能体现“会用 AI 做设计”而不是只会生成图片。

02 / Candidate Review

先淘汰错误，再谈美感。

阶段通过条件退回原因
结构初筛人物数、品类、轮廓和构图任务正确。多余人物、错误品类、主体被裁切或画面任务不成立。
角色复核发色、服装、道具和身份锚点保持稳定。脸部漂移、服装结构变化、手部/道具关系错误。
人工统一PS/AI 修正边缘、比例、文字与局部材质。需要用文案掩盖的结构错误，直接回到生成或重选。
交付放行有编号、状态、用途和下一步文件位置。没有来源说明、事实边界或无法被下一位复核。

03 / Applied Examples

同一套筛选逻辑，覆盖不同项目。

候选图用于说明筛选与统一方法；页面不公开未采用的私人素材、内部缓存或任何未确认授权的真实客户内容。

04 / Source Trail

从初稿回到源文件和说明。

每个通过候选都应能回到角色设定、提示词、透明素材、PSD/SVG 或生产说明。P0 角色源文件已在独立索引页公开；P1/P2 的包装和立牌候选也提供可编辑文件与边界说明。
