Case 08 / Beauty Commerce Visual

Aster Dew：
一支精华的整组商品视觉。

围绕同一支虚构植物精华，完成商品主图、材质细节、生活方式场景、平铺组合和详情页模块规划。

Scope主图 / 场景 / 详情页
Role产品锚点 / 视觉编排 / QA
OutputHero / Detail / Lifestyle / Flatlay
Status个人商品视觉案例

01 / Product Anchor

先把同一支产品固定下来。

所有画面固定瓶身比例、浅绿色磨砂玻璃、奶油色滴管盖、空白标签和圆角轮廓，只改变镜头、道具、光线与使用语境。

固定瓶型、盖型、主色、标签位置所有主图与场景图必须保留
可变石材、浴室、叶片、俯拍角度只改变氛围，不改变产品
拒绝瓶身变形、盖子更换、标签乱码直接退回候选，不用文字掩盖

02 / Visual Set

四张图，四个页面职责。

03 / Commerce Modules

从图像直接落到详情页。

01 / HERO

首屏识别

单瓶、留白、瓶型清楚，负责第一眼识别与后置标题。

02 / PROOF

材质细节

水珠、磨砂玻璃和滴管结构承担局部视觉说明。

03 / CONTEXT

使用场景

浴室晨光与植物道具补充生活方式，不虚构功效。

04 / SOCIAL

社媒平铺

三瓶组合与俯拍留白适合社媒首图和活动 KV 延展。

04 / Handoff

把源文件和事实边界一起交出去。

图像包
主图、细节、场景、平铺四类导出，保留命名与页面职责。
后期项
裁切、标签留白、反射控制、色彩统一与安全区检查。
待确认
真实成分、功效、净含量、认证、包装尺寸和供应商参数。
