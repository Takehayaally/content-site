Character Case / Scene Assignment

帧隙信使：角色在场景中承担任务。

从四视图出发，为角色写清“在什么地方、正在做什么、画面要让观众先看到什么”。这让 AIGC 画面不是泛用氛围图，而是可进入分镜的剧情候选。

Scope角色设定 / 场景关键帧

Status原创概念案例

01 / Character Brief

把角色写成一组稳定的视觉条件。

林澈的黑发、黑色内层、半透明冷蓝外套、弧形装置与红色回执签构成固定识别。每一项都兼顾远景轮廓与近景细节：即使环境更暗、动作更大，观众也能先读到人物归属。

  • 01
    轮廓锚点
    弧形装置和透明外套把人物从深色背景中分离。
  • 02
    颜色锚点
    冷蓝服务空间与科技感，红色回执签只承担局部叙事信号。
  • 03
    道具锚点
    装置、签条和手部关系需要在不同镜头中保持可解释。

02 / Scene A

地铁站：先读任务，再读世界。

这张画面的任务是“在拥挤的站台定位异常时间点”。构图把林澈放在右侧中近景，手部指向画面中心的发光信号；轨道、隔离带和人群只提供空间尺度，不能抢走任务焦点。

03 / Scene B

回执时刻：把动作收束成情绪。

第二张把同一角色从公共空间切到更近的情绪节点：回执签、手部动作与光源成为叙事中心。它用来测试近景里人物面部、透明材质和红色信号能否仍保持与设定板一致，而不是把每张图都做成同一个姿势。

04 / Prompt-to-QA

每一张候选都回到角色基线。

01 / INPUT人物与任务
02 / FRAME景别与视线
03 / GENERATE多候选探索
04 / QA锚点复核
