P0 / AI Manga Drama Case

街区修补社·错误出口

把一个原创角色变成一条可生成、可修复、可交接的竖屏漫剧镜头链：三盏方向灯把居民引向封闭出口，维修工程师柚铁只用一次诊断和一次锁定，把路还给行人。

IP街区修补社 / 柚铁
Format9:16 · 36 秒 · 6 镜头
Focus角色 / 动作 / 连续性
Status原创概念 · 研究性方案

00 / Animatic Preview

先交付可检查的节奏，再进入正式生成。

这是基于 OwlAI 场景实验、原创柚铁立绘和 AVU 镜头合同制作的静态 animatic/previs，用于检查镜头节奏、构图、状态变化和交接信息；不是正式动态成片，也不把网关实验图标记为 GPT Image 2.5 产物。

00A / Character PV

把角色、声音与字幕合成一条可观看的短片。

20 秒角色能力 PV，采用日语对白与中日对照字幕；它与上方 36 秒六镜头静态预演分别承担“观看成片”和“检查镜头合同”两种阅读任务。

01 / Hook

先让观众看懂问题，再展示工具。

首秒不是角色口播或世界观说明，而是一个可见矛盾：方向灯全部指向封闭出口。柚铁的职业身份通过检查、定位、锁定和复测被看见，观众不需要先读设定才能理解动作。

00—05s错误出口
05—10s柚铁入场
10—22s诊断与锁定
22—36s复测与离场

这条节奏沿用 AI Video Universe 的“故事卡 → 逐镜任务 → 首尾状态 → 交付检查”方法，但只保留与画面判断有关的决策。

02 / Character & Reference

一张图只负责一件事。

角色、工具、环境和光线不混成一张“万能参考图”。每个输入都有职责，生成失败时才能判断是身份漂移、工具变形还是空间跳变。

以上为网站已公开的原创概念资产。AI Video Universe 中登记的柚铁派生参考另有“私下测试 / 指定 Provider 受控测试”限制，本页不直接公开或上传那些受限文件。

03 / Six Shot Contract

每镜只承担一个主要结果。

镜头画面任务连续性 / 回退
S01 · 5s居民跟随三盏错误方向灯，在封闭出口前停下。锁定街区布局；失败时用两张状态静帧硬切。
S02 · 5s柚铁拉下透明护目镜，视线锁定偏转模块。Flare 探索构图后，Sunburst 锁身份；不要求口型。
S03 · 6s一只手稳住模块，另一只手检查接口，工具静置。手、模块、脸同空间；失败时拆成接近 / 接触 / 稳定三帧。
S04 · 6s磁铆锤从画外靠近，完成一次机械锁定。只改接触点；不做挥击、连招或特效爆炸。
S05 · 6s灯光状态变稳定，居民转向开放侧路。颜色和方向图形后期合成；模型不生成可读箭头。
S06 · 8s柚铁收工具、回头确认，再走出画面。只保留一次回头；身份漂移则回退为英雄静帧加确定性推近。

04 / GPT Image 2.5 Routing

把新模型用在不同的判断上。

GPT Image 2.5 的价值不是把整条漫剧交给一次 Prompt，而是把“探索”和“精修”拆开：Flare 用于快速比较构图，Sunburst 用于参考锁定和局部编辑。当前页面是 2.5-ready 方案，已有图像不是 2.5 生成记录。

阶段模型分工人负责的判断
方向探索Flare / low—medium从 3–6 个候选中选出最能读懂“错误出口”的构图。
角色与道具锁定Sunburst / high确认柚铁、护目镜、工作服与磁铆锤的关系没有漂移。
单变量修复Sunburst / high—xhigh只修手、接触点、灯光状态或背景局部，并保留前后对照。
多轮编辑Responses API + image input沿用同一上下文继续改，不重复塞入无关设定，降低版本混淆。

官方资料没有给出 2.5 相对 GPT Image 2 的统一百分比提升；本案例把可验证的模型分工、输入职责和编辑闭环写清楚。

05 / Production Spine

AI 漫剧能力，最后要落到交付。

01 / STORY钩子与节拍
02 / SHOT镜头合同
03 / QC连续性与失败修复
04 / HANDOFF字幕 / 声音 / 文件
  • 01
    编剧对齐
    用一句话说明异常、人物目标和结尾回报；不先堆世界史。
  • 02
    导演翻译
    把每镜拆成机位、景别、动作、状态变化和首尾条件。
  • 03
    生成与修复
    参考图按职责绑定；同一失败类别只改一个变量，保留回退方案。
  • 04
    后期交付
    字幕、方向灯图形、音效、配乐和可读文字后期完成，再过技术、叙事、音频、连续性和权利检查。
