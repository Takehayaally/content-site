Character Case / Consistency Lab

多角色一致性：先固定，再变化。

面对多套角色，不用“风格差不多”代替可交付的设定。每个角色先定义轮廓、主色、核心道具和不能漂移的部位，再把不同人物放在同一套复核规则中检查。

01 / Comparison

人物不同，复核逻辑相同。

照霜、雾灯和唐小满分别服务时间巡礼、深海维护与便利店叙事。它们在题材与主色上拉开差距，但三组设定都保留正侧角度、面部阅读、服装结构和签名道具，让后续分镜、组图或生成候选有明确的参照物。

角色可见锚点生成后优先检查
照霜 / 无昼巡礼浅色发型、深色外套、伞与日晷意象。伞的结构、服装分区、冷暖关系与时间系统符号。
雾灯 / 赤潮信标深海装备、信号焰、环礁维护语境。潜水装备逻辑、道具比例、材质与环境关系。
唐小满 / 星期八便利店暖色人物、门店制服与日常道具。面部年龄感、制服识别、手持物和日常场景比例。

03 / QA Gate

先拒绝漂移，再保留可用候选。

不同角色进入 AIGC 流程时，检查项可以复用：人物数是否正确、脸部和发色是否稳定、服装结构与关键道具是否保留、手部关系是否可信、背景是否支持而非吞没人物。满足这些基础后，才讨论构图、情绪与细节精修。
