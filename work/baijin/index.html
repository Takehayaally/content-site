Case 02 / Character Key Visual

白烬：用环境完成角色叙事

角色不是贴在背景上的立绘。服装、机械结构、雪地环境和冷光共同建立她所在的世界与行动状态。

Scope角色主视觉
Focus构图 / 氛围 / 视觉焦点
Output竖版关键视觉
Status原创公开案例

01 / Direction

把冷感、重量与行动性放在同一画面。

画面以低饱和雪地和机械结构建立冷感，再以角色的深色服装、发色与近景比例形成清晰焦点。环境不是装饰，而是解释角色所处的危险与技术语境。

  • 01
    前中后景建立纵深
    雪地碎片、角色与远景设施形成连续空间。
  • 02
    机械配件延续世界观
    装备的硬结构与服装柔性材质形成张力。
  • 03
    控制冷色里的明度节奏
    亮雪、暗服装和局部冷光让视线先到角色再阅读环境。

02 / Visual Logic

一张主视觉的阅读顺序。

01 / SIGNAL角色面部
02 / FORM服装轮廓
03 / CONTEXT机械装备
04 / WORLD雪地环境

03 / Review

主视觉之后，需要系统化补全。

当前案例能证明角色气质与叙事主视觉的组织能力，但不把单张 KV 包装成完整 IP 系统。后续若继续发展，应补齐稳定设定、表情与动作、关键装备拆解和跨场景一致性。
