Case 04 / Cross-border Product Visual

开放式耳机：跨境商品视觉

以虚构产品 AURALINK ARC 为对象，先建立多视角产品基准，再延展白底主图、充电收纳和桌面场景。

Scope商品主图 / 详情模块
Role产品定义 / AI 辅助生成 / 视觉 QA
Output主图 / 细节 / 场景图
Status商品视觉与页面编排

01 / Product Anchor

先定义同一件产品，再扩展图组。

产品锚点限定为深石墨色耳挂、圆角触控面、银色材质过渡、柔和青绿色状态灯和扁椭圆充电盒。先完成并审核白底主图，再以它作为参考生成细节与收纳画面，减少同一商品在不同图里改变结构、比例或材质的问题。

  • 01
    开放式形态
    用耳挂轮廓和外露声学区传达开放式佩戴概念，不把它画成入耳式或头戴式耳机。
  • 02
    商品阅读
    白底主图优先保证套装完整、轮廓清楚，并为页面中的人工文案留下空间。
  • 03
    后置文字
    图片不承担型号、参数和认证信息，避免把生成文字误当成正式商品信息。

02 / Detail System

先看多视角基准，再看收纳关系。

产品基准板统一左右耳、正侧后视角和充电盒结构；收纳图再核对内托、开盖与成对关系。后续场景只能改变背景和镜头，不得改变产品。

02A / Consistency Gate

同一产品，跨图只允许有限变化。

固定锚点耳挂轮廓、触控面、银色过渡、青绿色状态灯主图 / 细节 / 收纳 / 佩戴 / 通勤均须保留
可变因素镜头、背景、人物、桌面与光线只改变使用语境，不改变产品结构与比例
拒绝条件入耳式轮廓、左右耳不成对、盒体比例漂移直接退回候选，不用后期文字解释结构错误

03 / Lifestyle Reading

先让产品被看清，再进入使用情境。

场景图只改变镜头、桌面与光线，产品本体始终沿用同一套黑灰银耳挂、青绿色状态灯与扁椭圆充电盒锚点。这样页面中的每张图都能回指同一件产品，不用靠文字解释差异。

04 / E-commerce Modules

把图组直接翻译成详情页模块。

这组模块是面向跨境商品页的排版规划，先明确每张图承担的任务，再由人工补充正式参数与合规文案。

MODULE 01

Hero / 主图

套装完整、轮廓清楚、背景干净，负责第一屏商品识别。

MODULE 02

Material / 结构

放大触控区、耳挂与材质转折，支撑局部卖点说明。

MODULE 03

Context / 场景

用佩戴和通勤场景补充使用语境，不替代性能证明。

04A / Campaign Extension

同一产品，再延展一组广告与电商视觉。

广告延展沿用已核对的黑灰银与青绿色状态灯产品锚点，改变镜头和使用语境，不改变耳挂、触控面与充电盒结构。

05 / SKU & English Framework

把跨境商品页需要的 SKU 与英文信息先搭好。

颜色变体先以规格方向公开，不把尚未生成的独立渲染图伪装成成品；英文信息区只提供版式与卖点层级，不写未经产品资料确认的性能承诺。

GRAPHITE / 主 SKU

深石墨色；当前已完成主图、结构、收纳与场景图组。

MIST WHITE / 变体方向

雾白色；已定义配色方向，独立渲染图待生成与一致性验收。

DAILY CONTEXTScene module heading

06 / Handoff

交付时先交结构，再交画面。

主图组
01_hero / 02_detail / 03_charge，统一产品锚点与裁切安全区。
页面模块
模块标题、图片职责、留白位置和待补参数字段分开管理。
QA 门槛
左右耳配对、耳挂结构、材质边界、文字后置与事实边界逐项检查。

当前公开的是网页展示型交付；没有把未生成的雾白 SKU、未确认参数或供应商文件伪装成成品。

07 / Production Method

AI 负责候选，人负责统一与边界。

本案例的工作顺序是：定义产品结构与禁用项，生成白底候选，选择可用的产品锚点，再生成参考图并对比结构。公开页面只展示通过审核的精选图；SKU 色彩变体、正式参数与供应链资料需要在进入上架或生产前单独确认。
