Case 03 / Character Bible

赵霜：把识别度写进设定

把角色从一张氛围图中拆出来，用四视图、表情、道具和固定锚点说明“什么不能变、什么可以延展”。

Scope角色设定系统
Focus一致性 / 可复用性
Output四视图 / 表情 / 道具
Status原创公开案例

01 / Purpose

让角色在不同角度与情绪中仍然是同一个人。

角色设定页的价值不是信息越多越好，而是把最容易漂移的部分明确下来：轮廓、发型、服装结构、主色、关键配件和表情范围。

  • 01
    四视图控制结构
    避免服装、发型和配件在转身后失去逻辑。
  • 02
    表情定义角色弹性
    在保持五官锚点的前提下建立可用的情绪范围。
  • 03
    道具强化身份
    让配件具有结构和功能，而非随机增加装饰。

02 / Character Bible

设定信息的四个层级。

01 / SHAPE轮廓与比例
02 / STRUCTURE服装与发型
03 / EMOTION表情范围
04 / IDENTITY配件与道具

03 / Evidence

把设定页拆成可检查的部分。

04 / Review

设定不是终点，而是后续一致性的基线。

这套资料可以支持后续主视觉、动作与商品载体的延展。若进入更完整生产，还需要增加色值、材质说明、比例标尺和高频动作验证；当前页面不把这些未完成项写成已有成果。
