P0 Storyboard Case / Shot Handoff

白烬：三拍镜头交接包。

把“有三张好看的图”变成剪辑和编剧能继续讨论的镜头材料：每个关键帧明确时间段、叙事任务、角色状态、连续性条件和下一步需要补的素材。

Scope剧情关键帧 / 镜头标注
Focus节拍 / 连续性 / 交接
Output3 镜头故事包
Status原创静态预演

01 / Beat Map

三拍完成一次可读的行动。

本段以“抵达异常区域 → 读取记忆线索 → 离开并追踪”为最小叙事单元。它用于验证镜头关系与素材要求，不把静态预演写成已完成的动画、配音或漫画连载。

SHOT 01 / 0–3 s抵达

建立人物、环境与异常来源。

SHOT 02 / 3–6 s读取

把线索和人物反应推到近景。

SHOT 03 / 6–9 s追踪

用行动方向收束并接向下一段。

02 / Key Frames

每一张图都要有明确职责。

03 / Continuity Notes

后续素材必须接住这些条件。

镜头项必须连续允许变化
角色白发、深色外套、机械肩部、红色局部与行动装备。景别、姿态、表情和光源。
道具与信息记忆结晶的红色信号、设备与人物的接触关系。结晶位置、近远景尺度和环境密度。
镜头方向人物视线与追踪方向须能从读取镜接到行动镜。机位高度、前景遮挡和空间展开方式。

生成时会先对照角色设定板筛候选，再检查镜头职责、人物数、手部/道具关系与方向；不通过的图不进入交接包。

04 / Handoff List

让下一位参与者知道拿什么、补什么。

编剧核对
三拍的信息是否形成“抵达—读取—追踪”的因果；若不足，先补叙事目标而非堆画面。
剪辑核对
镜头编号、景别递进、视线与动作方向；进入动态前先标出预计停留时长和转场位置。
视觉交付
通过的关键帧、角色锚点、道具说明、提示词版本与待补镜头清单分开归档。

本页是原创角色的静态镜头交接研究，不宣称已完成动态生成、声音、正式剪辑、客户委托或公开发布。
