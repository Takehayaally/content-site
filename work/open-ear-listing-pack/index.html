P1 / P2 3C E-commerce Delivery

开放式耳机：不是五张图，是一份商品交付包。

将原创 3C 商品视觉按页面职责、裁切规格、质量门和文件交接重新组织。目标是让运营、详情页设计和后续视觉人员拿到可继续使用的图组，而不是从一批零散效果图重新判断。

Scope3C 主图 / 详情页 / 场景
Role产品锚点 / AIGC / QA
Output5 图交付 / 模块映射
Status原创概念 / 非真实上架

01 / Delivery Map

一张图，只承担一个明确任务。

交付图组先按电商页面职责编号，避免主图、结构图和场景图互相替代。图片中不生成价格、性能参数、认证或英文卖点；需要确认的商业文案由页面后置，避免将生成文字误写为产品事实。

文件页面职责放行检查
01_hero第一屏商品识别：整套耳机、充电盒和结构轮廓。主体完整、白底干净、左右耳成对、无伪造文字。
02_detail详情页结构区：耳挂、触控面、声学区与材质关系。形态仍为开放式耳挂，材质边界不漂移。
03_charge收纳模块：开盖、内托、耳机与盒体的配对关系。左右耳、盒体比例、开盖关系正确。
04_wear / 05_context佩戴与通勤场景：解释位置与日常使用语境。耳挂位置可信，产品仍可清晰辨认并保留文案留白。

02 / Asset Set

主图、结构、收纳与场景构成最小闭环。

03 / Handoff Notes

把素材交给下一页，而不是交给猜测。

open-ear-listing/
├─ 01_anchor/ hero 图、产品锚点与禁用项
├─ 02_pdp/ detail / charge 结构模块
├─ 03_lifestyle/ wear / context 场景模块
└─ 04_qa/ 结构、配对、裁切、文字后置检查

当前可交付的是原创概念图组、页面职责和 QA 口径。色彩变体、真实型号、参数、平台规则、合规文案和供应链资料不在本页编造，需由真实商品资料确认后再进入上架版本。
