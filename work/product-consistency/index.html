Case 05 / Product Consistency & QA

产品一致性与跨图 QA

用同一款开放式耳机说明：如何固定产品锚点、允许场景变化、拒绝结构漂移，并把检查结果交给详情页与后续文件。

Scope3C 商品图组 / 详情页
Role产品定义 / 跨图复核 / QA
Output锚点表 / 对比板 / 验收门
Status个人概念练习 / 非真实上架

01 / Anchor Sheet

先写清楚什么不能变。

形态
开放式耳挂，外露声学区，不得变成入耳式或头戴式。
材质
深石墨主体、银色过渡、柔和青绿色状态灯。
套装关系
左右耳机成对，充电盒为扁椭圆形，开盖与内托关系稳定。

02 / Comparison Set

用图组而不是单图判断一致性。

03 / QA Output

把判断交付给下一步，而不是停在审美意见。

PASS

结构通过

产品轮廓、左右配对和材质边界保持稳定。

REJECT

候选退回

结构漂移、错误品类或伪造文字直接拒绝。

HANDOFF

进入页面

通过图再进入详情页模块、裁切与文件归档。
