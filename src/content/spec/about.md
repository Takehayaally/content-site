# 关于 NOVA

NOVA 是一个以二次元视觉设计、原创 IP 与谷子/周边表达为核心的个人作品与研究站。

这里先展示能说明设计判断的案例：角色视觉、主视觉、商品化表达与完整呈现逻辑。工具只服务于创意、迭代和质检，不替代审美判断、可落地的设计选择或最终交付责任。

## 当前方向

- 二次元 IP 的角色视觉与主视觉设计。
- 谷子、周边和物料的系列化表达。
- 数字短片前期、角色一致性与视觉质检方法。
- 让创作过程更清晰、更可复核的工作流研究。

## 公开边界

作品集只收录原创或权属清楚、适合公开展示的内容，并尽量说明设计范围。正在完善的项目会明确标注为进行中；未授权素材、第三方 IP、未经核验的效果数据和商业承诺不会作为能力证明。
