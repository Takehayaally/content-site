# 《白夜余烬》扩展角色

## 沈砾

- 年龄：29 岁，成年人
- 身份：灰庭城记忆档案馆机械师
- 性格：谨慎、嘴硬、擅长把复杂故障拆成可执行步骤
- 外观识别：黑发、工具肩带、旧式机械义手、档案编号牌
- 剧情作用：负责维护白烬的余烬冠，并发现馆内存在被人为改写的设备日志
- 配件功能：机械义手用于隔热取样；编号牌是档案馆权限钥匙；折叠工具臂可校准余烬容器

## 洛弥

- 年龄：32 岁，成年人
- 身份：记忆医学科主治医师
- 性格：冷静、直接，反对以“治疗”为名替患者决定该忘记什么
- 外观识别：酒红短发、白色医疗外套、记忆波形耳坠、透明诊断片
- 剧情作用：为白烬提供记忆稳定治疗，并调查裂忆病是否由城防系统诱发
- 配件功能：诊断片显示记忆裂隙；耳坠同步脑波异常；腰侧封存盒保存只读样本

两名角色均为《白夜余烬》的原创成年人角色，设定图中的文字仅作视觉辅助，本文件为正式设定依据。
