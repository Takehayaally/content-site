# 赤潮信标

原创深海幻想 IP｜角色视觉、世界观、配件逻辑与周边落地案例

## 一句话概念

赤潮升空后的第四十年，海面被发光孢子云覆盖，人类迁居环礁下方的垂直城市。首席信标潜航员「雾灯」负责进入失压海域，重新点亮维持航路与城市供氧的深海信标。

## 世界观

- **赤潮环礁**：围绕旧时代海沟建设的垂直聚落。上层是气象与贸易平台，中层是居住区，下层连接维护坞与深潜井。
- **赤潮**：悬浮在海面与低空的发光孢子潮。它会干扰导航并腐蚀普通材料，但也能被转换为能源。
- **信标链**：分布在海沟中的人工导航节点，负责校准洋流、照明航路并向环礁输送稳定能源。任一节点熄灭，都可能让整段航路失联。
- **潜航员**：通过压力膜装备进入高压区的专业人员。每次任务都要在氧量、潮汐与记忆干扰之间做取舍。

视觉关键词：深海工业、黑色潜航装备、荧光青、警示红、半透明压力膜、风暴海面、发光海沟。

## 角色：雾灯

- 年龄：27 岁，成年人
- 身份：赤潮环礁首席信标潜航员
- 性格：克制、判断快、对同伴负责；不擅长解释自己，但会把撤离路线留给最后一个人
- 外观识别：白色短发、红色瞳孔、黑色潜航服、青色压力环、红色信号焰胶囊
- 角色目标：找回十二年前失联的第一代信标，并确认父亲所在的维护队是否真的全员遇难

## 配件功能

| 配件 | 作用 | 设计理由 |
|---|---|---|
| 压力环 | 读取局部压强、赤潮频率和返航方向；危险时展开为半环警示灯 | 构成角色头部轮廓与远距离识别点，不是装饰光环 |
| 呼吸领 | 自动均压、过滤赤潮孢子、记录剩余氧量 | 将现实潜水装备语言转译成简洁的二次元造型 |
| 压力膜披片 | 在高压水流中形成缓冲层，可快速拆换受损模块 | 半透明材质为黑色主体增加层次，同时承担功能 |
| 信号焰胶囊 | 标记救援坐标、释放高亮红焰，也可保存最后一段任务记录 | 红色视觉锚点，适合转化为挂件、胸针和包装图形 |
| 模块潜航刃 | 割断缆绳、清理沉积物、撬开维护舱；不是单纯战斗武器 | 体现职业属性，避免只靠“酷”而无用途 |

## 周边落地

- 亚克力立牌：约 150 mm 高，3 mm 透明亚克力，椭圆插槽底座
- 珐琅胸针套装：压力环约 38 mm，信号焰约 28 mm，蝴蝶扣
- 信号焰胶囊挂件：约 70 mm，透明树脂外壳、金属旋盖与龙虾扣
- 镭射收藏卡：A6，局部冷烫银与海浪纹镭射膜
