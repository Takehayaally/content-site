# 《街区修补社》视觉规范（展示与生产沟通草案）

> 版本：2026-09-02。本文档用于统一柚铁角色、维修工具、服装和快闪店物料的视觉语言；不是注册商标手册或供应商最终色样。真实生产前仍需复核字体授权、CMYK/专色、刀模、材质和安全规范。

## 1. 品牌性格

可靠、爽快、可学习、尊重劳动。视觉重点是“把复杂维修讲清楚”，不是把市政工具武器化或把小体型角色幼态化。每个大工具都要能回答用途、操作方式和安全边界。

关键词：街区服务、模块维修、机能服、反差尺度、公开技能、可拿取零售、夜间安全。

## 2. 色彩基准

| 色彩角色 | 屏幕参考 | 使用建议 |
|---|---|---|
| 石油蓝 | `#1E4355` | 夹克、货架主色、背景块 |
| 石墨黑 | `#20282D` | 工装裤、工具杆、正文与结构线 |
| 安全黄 | `#F2C84B` | 磁铆锤磁头、护目镜侧护片、警示条 |
| 烧橙 | `#D86432` | 柚铁发色、里层、定位模块与活动提示 |
| 翡翠绿 | `#2FA66A` | 眼睛与少量状态指示，不作为大面积装饰 |
| 象牙白 | `#F2EBDD` | 内搭、技术纸、背卡留白和说明区 |

石油蓝/石墨约占 55%—70%，象牙白 15%—25%，安全黄与烧橙各作为 5%—15% 的功能色。警示黄只用于需要被看见的边缘、工具或标记，不能把所有背景做成施工警戒条。

## 3. 图形语言

- 模块网格：用可替换的矩形、孔位和编号表现城市设施模块；网格要服务于结构说明，不做无意义科技背景。
- 安全条：黄黑或黄蓝斜纹仅用于危险边缘、工具握持区和动线提示，保持节制并避免仿制真实机构标志。
- 工具轮廓：磁铆锤、护目镜、斜挎包和耗材管采用清晰外轮廓+局部剖面，优先表现可拆、可换、可维修。
- 维修贴片：橙色小模块可作为“故障已定位/待替换”的统一图形，避免随机贴纸和不可读编号。
- 快闪店：穿孔钢板、浅桦木、米灰混凝土与标准货架构成真实基底；科幻元素只做局部标识。

## 4. 角色与尺度一致性

柚铁为 20 岁成年人，必须保留短烧橙发、石墨底层发、翡翠绿眼睛、石油蓝机能夹克、石墨工装裤、黑黄工作靴和少量雀斑。2.1 m 磁铆锤是维修工具，不是战斗武器；展示中需通过伸缩柄、双侧磁头、透明支架或工具台说明其收纳与操作逻辑。

禁止：幼态脸和儿童比例、短裙/高跟鞋替换工装、把护目镜画成装饰眼罩、将色标耗材管画成药剂或能量瓶、让巨锤占据无法通行的门店动线。

## 5. 信息层级与版式

1. 第一层：柚铁轮廓或磁铆锤大形，负责快速识别。
2. 第二层：维修编号、模块名称、故障状态和安全提示，负责解释服务属性。
3. 第三层：材质、尺寸、可拆结构和生产备注，负责商品化沟通。

说明卡和背卡采用清晰网格、左对齐和统一编号；核心文字不小于目标尺寸下可读的最小字号。生成图中的随机文字、条码和警示语必须重新排版，不直接送印。

## 6. 生产与陈列基线

- 亚克力立牌/挂件：标出透明区、白墨、刀模、外轮廓和底座插槽；展示效果图与生产版分目录。
- 服装/箱包：除外观图外，需记录面料、拉链/扣件、反光带、口袋和可拆模块，避免仅凭渲染图承诺工艺。
- 工具模型：标记缩比、磁头、伸缩柄、透明支架和可拆件；小尺寸零件需做强度与误吞风险评估。
- 快闪店：维持真实货架、价签槽、补货空间、通道宽度和收银动线；角色海报只占一处传播位，不用巨型道具堵塞入口。
- 已有柚铁亚克力立牌概念生产文件应保留“作品集级、未工厂签样”的边界描述。
